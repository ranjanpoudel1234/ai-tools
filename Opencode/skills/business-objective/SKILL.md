## Process Flow

### Step 1: Collect Information
Ask the user:
1. "What time period are you documenting? (e.g., 'Q1 FY23', 'September 2024', 'FY22')"
2. "Please share your rough notes of work activities, accomplishments, and contributions during this period. Include commitments met, learning activities, reliability improvements, and team/culture contributions. Don't worry about formatting - just brain dump everything you did!"

### Step 2: Parse and Map
For EACH item the user mentions:
1. Identify which Business Objective(s) it demonstrates
2. Identify which specific sub-criteria it falls under (1A, 1B, 1C, 2A, 2B, 3A, 3B, 3C)
3. Note the specific activity/contribution and how it demonstrates E3 (Experience, Efficiency, Execution)
4. Identify any quantifiable metrics or impacts mentioned
5. **CRITICAL**: Ensure EVERY detail is captured - create a tracking list as you go

### Step 3: Proactively Extract More Details Through Targeted Questions
**THIS IS A CRITICAL STEP - DO NOT SKIP**

After initial parsing, analyze the criteria coverage and ASK THE USER targeted questions to extract more details:

1. **Review criteria coverage**: Identify which sub-criteria have few or no examples
2. **Analyze user's work**: Look at what they mentioned and identify opportunities to extract more details that could fit underrepresented criteria
3. **Ask targeted probing questions** based on what's missing. Examples:

**For Objective #1 (Deliver Business Priorities while Strengthening Technology Foundation):**
- If 1A (Deliver Key Initiatives) is light: "You mentioned [X work] - which key initiative did this support? (e.g., Standardized Planning, LUPE, Driver App, Inventory Hub, Sublet Management, Service Ops Modernization, Data Center Migration, APIM, etc.)"
- If 1A is light: "What sprint commitments, release dates, or milestones did you meet this period?"
- If 1B (Improve Delivery Capabilities) is light: "Did you contribute to Developer Excellence, automation, CI/CD improvements, or automated testing? Any work on code quality or development processes?"
- If 1C (Innovation R&D) is light: "Did you research AI/GenAI, participate in Innovation Garage, attend DevOps Days, or contribute to D2U/Impact to U initiatives? Any technical spikes or prototyping of new technologies?"

**For Objective #2 (Predictable, Reliable and Secure Operation - Achieve More with Less):**
- If 2A (Cost/Efficiency) is light: "Did any of your work reduce costs, optimize storage/resources, improve productivity, or drive efficiency? Any work that helps us 'achieve more with less'?"
- If 2A is light: "Did you reduce support needs through better design or automation? Any optimization work?"
- If 2B (Quality/Security/Reliability) is light: "Did you implement any monitoring, observability, security controls, or SLAs/SLOs? Any work improving system reliability, performance, or quality?"
- If 2B is light: "Did you work on Application Insights, alerting, error handling, code quality improvements, or security assessments?"

**For Objective #3 (Strengthen the Technology Organization through Talent):**
- If 3A (Associate Engagement) is light: "Did you participate in AVS action plans, team building, retrospectives, celebrations, or hybrid/in-office activities? Anything contributing to team culture?"
- If 3B (Development/Growth/Learning) is light: "What learning activities did you pursue? Training, courses, certifications? Did you mentor anyone or lead knowledge sharing sessions?"
- If 3B is light: "Do you have development plans or IDP goals you're working on? What skills are you developing?"
- If 3C (Performance/Talent) is light: "Did you participate in interviews, refer candidates, or help with hiring? Did you provide feedback to colleagues or support their development?"

**Cross-cutting questions to extract hidden details:**
- "You mentioned you helped [person] with [thing] - can you tell me more about what you taught them or how you supported their growth?" (Maps to 3B or 3C)
- "When you implemented [feature] - what key initiative or business priority did this support?" (Maps to 1A)
- "Did this work improve efficiency, reduce costs, or help us achieve more with less?" (Maps to 2A)
- "Did you share your knowledge about [topic] with the team in any way?" (Maps to 3B)
- "Were there any metrics or numbers around the impact of [work item]?" (Enhances any category)
- "How did this work demonstrate Experience, Efficiency, or Execution (E3)?"

**Instructions for this step:**
- Present these questions in a conversational, helpful way
- Group related questions together
- Explain WHY you're asking (e.g., "I want to make sure we capture how your work aligns with [CurrentYear]'s focus on achieving more with less")
- Allow the user to answer what's relevant and skip what's not
- Use their answers to enrich the documentation

### Step 4: Transform to Professional Language
For each activity:
- Use strong action verbs: Delivered, Achieved, Mastered, Implemented, Led, Drove, Optimized, Reduced, Improved, Mentored, Facilitated, etc.
- Use STAR format where applicable (Situation, Task, Action, Result)
- Quantify impact where possible (percentages, time saved, costs, number of people affected)
- Frame in terms of business value and team impact
- Use past tense consistently
- Make it concise but impactful
- Emphasize outcomes and results

### Handling Multiple Objectives
Some activities may demonstrate multiple objectives. In these cases:
- Include the activity in ALL relevant objectives and sub-criteria
- Frame the statement slightly differently to emphasize the specific objective aspect
- Highlight different E3 (Experience, Efficiency, Execution) dimensions
- Example: "Implemented monitoring solution that reduced costs"
  - In Objective #2B (Quality/Reliability): "Implemented comprehensive monitoring solution with Application Insights, increasing system visibility and enabling proactive issue resolution"
  - In Objective #2A (Cost/Efficiency): "Implemented monitoring solution that identified cost optimization opportunities, reducing operational expenses by 35% and achieving more with less"

### Ensuring Completeness
- As you parse the user's input, maintain a checklist
- Before finalizing, cross-reference every input item against your output
- If something doesn't fit any objective, flag it for the user to discuss
- Track coverage across all 8 sub-criteria (1A, 1B, 1C, 2A, 2B, 3A, 3B, 3C)
- Ensure examples demonstrate alignment with E3: Experience, Efficiency, Execution

### Professional Tone with STAR Format
Where applicable, use STAR format:
- **Situation**: Context or challenge
- **Task**: What needed to be done
- **Action**: What you did
- **Result**: Impact achieved

Example: "Situation: Production system lacked visibility into performance issues. Task: Needed to enable proactive monitoring. Action: Implemented Application Insights dashboard with custom metrics and alerting. Result: Reduced mean time to detection by 75% and enabled self-service analytics for product team."

Condensed for bullet: "Implemented Application Insights dashboard with custom metrics and alerting, reducing mean time to detection by 75% and enabling self-service analytics for product stakeholders"
