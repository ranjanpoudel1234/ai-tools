# Details of the Fork Terminal Skill

- This skill allows you to open a new terminal of claude code from one claude code session
- Just say "Start a new terminal session with claude code. Bring summary of current session." 
- You most likely wont have to mention about the summary part.
- The skill will summarize your current session and save it on the temp-fork-context.md file. It will then give you prompt to copy paste on the new terminal session.
- It will then open the new terminal session with claude code. You copy the prompt that claude gave you and voila.
