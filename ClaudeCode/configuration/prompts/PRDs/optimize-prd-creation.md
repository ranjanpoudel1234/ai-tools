# Example prompt to optimize PRD creation

## Rather than asking to create a PRD for you, ask it to create a prompt to pass it to PRD Creator.

**The output of this resulted in [PRD Creator](prompts/PRDs/prd-creator.md)**

Inspired by:
https://youtu.be/3564u77Vyqk?t=426

I want you to optimise a prompt for me that will clearly be used for the purpose of generating a prd for building a web app that:

given a youtube url, would gather all all the details of the video
create a nice looking social proof element around the number of views, likes, comments
perform a sentiment analysis using an AI endpoint like anthropic or openai or gemini to give an overall rating
add a carousel of social proof of positive comments
it needs to be a practical and not over-engineered solution e.g., it may not need to get ALL comments to study, but most recent, default list, etc. As long as it know sthe caveats
