# sync-todos.md

This command will synchronize the `todos.md` file with the current state of tasks.

**Instructions:**

1.  Read the contents of `todos.md` using the `TodoRead` tool.
2.  Based on the current project context and any new information, update the `todos.md` file using the `TodoWrite` tool to reflect completed tasks, add new tasks, or reorder existing ones.
3.  Ensure that the checkboxes `[ ]` for incomplete tasks and `[X]` for completed tasks are correctly maintained.
4.  Divide the tasks into groups of what are Pending, InProgress and Completed.
