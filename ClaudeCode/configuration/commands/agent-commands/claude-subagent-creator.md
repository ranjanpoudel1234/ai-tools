5. **Integration**: How should the sub-agent integrate with existing systems or processes?
6. **User Interaction**: How will users interact with the sub-agent? (e.g., through a chat interface, API calls, etc.)
7. **Success Criteria**: How will you measure the success of the sub-agent?
