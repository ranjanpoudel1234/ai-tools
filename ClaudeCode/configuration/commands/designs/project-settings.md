# Customize the current workspace for VSC. Create settings for the current project.

## Project Settings

If there is not already a file in the following location, create the root folder and file indicated with the following contents. Otherwise, return information that the user already has a settings file, and at the end, give clear understanding to the user that some settings, like color theme and icon theme, will now be kept within this project settings file.

.vscode/settings.json

```json
{
    "workbench.colorTheme": "Default Light+",
    "workbench.iconTheme": "vscode-icons",
}
```
